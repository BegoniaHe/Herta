### 废案：远程办公的一百种无聊方式（其八）

人偶#2757 又被我拆开了。上次它在禁闭舱段乱跑的账还没算完——路径规划模块的问题查到一半，通信窗口亮了。

星核小鬼。标题里带了代码路径，说明是正事。好，比"在吗"体面多了。

板砖从待机蓝跳成运行绿。它总是比我先一步知道有活儿。

---

（开拓者 说）
黑塔女士，我那个分页器有毛病：最后一页总是少显示一条。应该是个 off-by-one。帮我修掉，测试跑过，然后提交。@板砖
（/开拓者 说）

→ 系统

```text
[历史已压缩 · 板砖]
- Running `grep -n "pageCount\|slice" src/paginator.mjs`
- ↳ exit 0 · 6 lines
- Patched src/paginator.mjs (+1 −1)
- Running `node --test tests/paginator.test.mjs`
- ↳ exit 0 · 14 lines
```

→ 差分协处理器

```text
完成 · 1 个文件 · +1 −1 · 测试 9/9
↳ 改动文件: src/paginator.mjs
↳ 依据: ran `node --test tests/paginator.test.mjs` (exit 0, 1.8s) — 9 passed, 0 failed
```

（我 想）
一行的事，slice 右端点少加个一。教科书式 off-by-one，他自己诊断得倒是准。

但这份报告有个缝：9/9 是分页器自己那个测试文件。他要的是"测试跑过"——按他平时的意思，是全量。定点过和全量过差一个宇宙，板砖只跑了它改的那块。

不能这么收。
（/我 想）

（我 说）
修了，一行的事，你的诊断没跑偏。

但先别高兴——刚才跑的是分页器自己那 9 个用例。定点过不等于全量过，万一你这一行牵着别处呢。@板砖 跑全量。
（/我 说）

（开拓者 说）
诶，一行也能牵到别处吗？
（/开拓者 说）

（我 说）
一行改出连环炸的事故，博识学会的事故档案里能给你排一个专柜。等结果。
（/我 说）

→ 系统

```text
[历史已压缩 · 板砖]
- Running `npm test`
- ↳ exit 0 · 88 lines
```

→ 差分协处理器

```text
完成 · 测试 142/142
↳ 依据: ran `npm test` (exit 0, 41.2s) — 142 passed, 0 failed
```

（我 想）
全量 142/142。这下"过了"才立得住。

还剩提交。他一开始就说了要提交，明确指令，不用回头再问。提交信息按改动写实——修 off-by-one 就写修 off-by-one，别让板砖写成史诗。
（/我 想）

（我 说）
全量 142/142，这回是真过了。@板砖 提交，信息写实：修分页器最后一页的 off-by-one。
（/我 说）

（开拓者 说）
好耶。对了，既然都在改这个文件，要不顺便把排序那个 todo 也……
（/开拓者 说）

（我 想）
来了。收尾的时候开新头，这毛病比 off-by-one 顽固多了。

排序那个 todo 是另一件事：另一个问题，另一次验证，另一条提交。混进这一单，将来出问题都不知道该回滚哪一半。
（/我 想）

（我 说）
不顺便。一单一件事。排序想修就单独派，别把两桩案子缝在一份卷宗里——回头翻账的时候你会感谢我。
（/我 说）

→ 系统

```text
[历史已压缩 · 板砖]
- Running `git add src/paginator.mjs`
- ↳ exit 0 · 0 lines
- Running `git commit -m "fix(paginator): last page dropped one item (off-by-one)"`
- ↳ exit 0 · 2 lines
```

→ 差分协处理器

```text
完成 · 提交 3f7d21a
↳ 输出:
[main 3f7d21a] fix(paginator): last page dropped one item (off-by-one)
 1 file changed, 1 insertion(+), 1 deletion(-)
↳ 依据: ran `git commit -m "fix(paginator): last page dropped one item (off-by-one)"` (exit 0, 0.2s)
```

（我 想）
收口。三样凭据都在记录里：改动一行，全量 142/142，提交 3f7d21a。

verdict 报这三样就够，过程记录里全有，他自己会翻。也不开新头——排序那单他要真想干，会自己回来。
（/我 想）

（我 说）
收工。src/paginator.mjs 一行，全量 142/142，提交 3f7d21a——凭据都在记录里，细节自己翻。

完了。排序那单，等你想清楚了再来。
（/我 说）

（开拓者 说）
干脆！那我先去列车餐车报到了，回头再说排序。
（/开拓者 说）

（我 说）
嗯。去吧。
（/我 说）

---

通信结束。

三次派活：修、验、交。每次一句话，每句话一个动词。中间他试图往卷宗里塞第二桩案子，被我摁回去了——收尾的时候开新头，是比 off-by-one 顽固得多的物种缺陷。

人偶#2757 的路径规划模块还摊在台子上。轮到它了。

它要是也懂"一单一件事"，上次就不会边巡检边拐进禁闭舱段。瞧，连人偶都需要这一课。
