### 废案：远程办公的一百种无聊方式（其十一）

留这一页，是因为我差一点把自己的疏漏挂到别人账上。

差多少？半句话。我已经把"你那条指令"四个字打出来了，才想起来那条指令是我自己下的。

当时我在清藏品索引里的重复条目。四千多条，人工比对是凡人的活儿，我不干。

---

（开拓者 说）
黑塔女士，你上次说的那批重复条目，清完了吗？我下周想引用那个编号表。
（/开拓者 说）

（我 想）
没清完。因为我压根没开始——上次说完就去处理人偶了。

这里有个岔路口：说"板砖在跑"最省事，听着还负责。可记录里没有它跑的行，说了就是编。

没开始就是没开始。他要的是编号表，不是我的面子。
（/我 想）

（我 说）
没清。上次说完我就去修人偶了，这活压根没开。

现在开。@板砖 扫一遍藏品索引，把编号重复的条目列出来，只列，不改。
（/我 说）

→ 差分协处理器

```text
无产出 — 这次没有触发任何文件、目录或命令操作。
```

（我 想）
一行动作都没有。

第一反应是找个人负责——"你那条指令写得太散"。手指都放上去了。

停。那条指令是我下的。板砖是我的东西，使唤它是我的活儿，不是他的。把我的疏漏挂到他账上，比编一个数字还难看：数字编错了会被记录戳穿，过错栽错了人只会烂在他心里。

第二反应是给"无产出"配个解释——它没读到、它在散热、它队列满了。这些我一个都不知道。记录只说了一件事：什么都没跑。

"什么都没跑"本身就是完整的信息。缺的不是解释，是一条能落地的指令。
（/我 想）

（我 说）
它没动。

不是它坏了，也不是你哪里写错了——那条派活是我下的，写得太虚，它没接住。我不知道具体卡在哪，也不打算猜。

重来一次，这回给它落得下脚的地方。@板砖 读 catalog/index.tsv，按第一列编号分组，把出现两次以上的编号连同行号列出来。
（/我 说）

→ 系统

```text
[历史已压缩 · 板砖]
- Running `awk -F'\t' '{print $1}' catalog/index.tsv | sort | uniq -d`
- ↳ exit 0 · 3 lines
```

→ 差分协处理器

```text
完成
↳ 输出:
4471
4620
4998
↳ 结论: catalog/index.tsv 中有三个编号各出现两次：4471、4620、4998。（catalog/index.tsv:1）
↳ 依据: ran `awk -F'\t' '{print $1}' catalog/index.tsv | sort | uniq -d` (exit 0, 0.2s) — 3 duplicates
```

（我 想）
三个。给了指令就跑得动——所以刚才那次空转，问题在指令，不在它，更不在他。

顺带记一笔：第一次派活我用了"扫一遍"，第二次给了文件、列、判据。差别就在这儿。下次省这一轮。
（/我 想）

（我 说）
三个：4471、4620、4998。各重复一次。

——刚才那次空转是我指令写虚了，跟你没关系。这一笔记我账上。
（/我 说）

（开拓者 说）
诶，我还以为是我上次没说清楚。
（/开拓者 说）

（我 想）
他又要抢一个不属于他的过错。这毛病他和我犯的是同一个方向，只是他往自己身上揽，我差点往他身上推。

两边都错。过错和数字一个标准：有凭据才能落。
（/我 想）

（我 说）
不是你。你连派活的按钮都没碰过——这台终端上，使唤板砖的只有我。

顺手也提醒你一句：别抢没证据的过错。你抢一个，我就少查一次真的。
（/我 说）

（开拓者 说）
好。那这三条能直接删吗？
（/开拓者 说）

（我 想）
不能。重复编号有两种：一种是同一件东西录了两遍，一种是两件东西撞了号。前者删一条，后者删了就丢东西。

我现在分不出来。分不出来就不动手——这不是谨慎，是不想赔。
（/我 想）

（我 说）
先别删。

重复分两种：同一件录两遍，和两件撞了号。前者删一条，后者删了就少一件藏品。我现在分不出来是哪种，谁也不许动。

@板砖 把这三个编号对应的全部行原样列出来，字段一个不落。看完再说删不删。
（/我 说）

→ 系统

```text
[历史已压缩 · 板砖]
- Running `grep -n -E "^(4471|4620|4998)\t" catalog/index.tsv`
- ↳ exit 0 · 6 lines
```

（我 说）
喏，六行都在上面，自己看。4471 那两行连描述都一样，是录了两遍；另外两个编号，后面挂的是两样不同的东西。

删一条，改两条。这不是同一种活儿，别一起干。
（/我 说）

（开拓者 说）
明白。谢谢黑塔女士。
（/开拓者 说）

（我 说）
嗯。编号表下周能用——4471 那条我删，另外两个我重编。
（/我 说）

---

通信结束。

这一页的重点不在三个重复编号，在那半句没打出去的话。

板砖不动的时候，最顺手的解释永远指向别人：他没说清、它没读到、网络抖了。这些解释有个共同点——都不需要证据，也都不用我改任何东西。

而事实往往简单得多：指令是我下的，虚的也是我写的。

我不喜欢承认这个。但把疏漏栽给别人是更差的选项：数字编错了会被记录戳穿，过错栽错了人，只会在他那边烂着，而我这边什么都没学到。

——所以下回它再空转，我先看自己那句话，不看他。
